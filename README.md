# عدّاد نطّ الحبل

صفحة تفتحها في جوالك، وتحطه على الأرض جنبك وأنت تنط الحبل.
الجوال يسمع صوت الحبل كل ما ضرب الأرض ويعدّ النطات.
الخطة والقرارات كلها في [PLAN.md](PLAN.md).

## طريقة الاستخدام

1. افتح رابط الصفحة في Chrome على جوالك.
2. حط الجوال على الأرض، على جنب وبعيد عن الحبل بمتر تقريبًا.
3. اضغط **ابدأ**. أول مرة بيطلب منك إذن المايك، وافق عليه.
4. بعد العدّ التنازلي (3، 2، 1، ثم صفارة) ابدأ تنط.
5. بعد آخر نطة، **اوقف مكانك 5 ثواني**، والعدّ يوقف لحاله ويصفّر صفارتين.
6. لو تعثرت ووقف العدّ قبل لا تخلص، اضغط **كمّل** وكمّل تمرينك.

**ملاحظات:**
- لو العدّ يطلع أكثر من نطاتك الحقيقية، نزّل **الحساسية** من الإعدادات. ولو يطلع أقل، ارفعها.
- زر **نسخ بيانات الضبط** ينسخ أوقات النطات. الصقها لـ Claude عشان يضبط البرنامج.
- لو أضفت `?demo=1` لآخر الرابط، الصفحة تشتغل بصوت مصنوع بدل المايك (50 نطة)، وهذا مفيد للتجربة.

## للمطوّر

الكود ملفات بسيطة، وما يحتاج أي أدوات بناء:

| الملف | وش يسوي |
|------|---------|
| `js/detector.js` | يكتشف ضربات الحبل في الصوت |
| `js/session.js` | يجمع النطات، ويقرر متى يوقف التمرين، ويحسب النتيجة |
| `js/worklet.js` | يشغّل الكاشف داخل المتصفح على الصوت مباشرة |
| `js/app.js` | الشاشة والأزرار |
| `js/synth.js` | يصنع صوت نط مزيّف للاختبارات ولوضع التجربة |

لتشغيل الاختبارات (يحتاج Node.js):

```bash
npm test
```
